# HensleyXRprojects
for class

How to set up for XR development 

change build to android, make sure scene is in it
change name and company
project settings, XR plug in management
check open XR for both android and pc
Open XR - Add oculus touch and meta quest touch controller profile to both windows and android, and make sure meta quest support is checked in android
fix any errors in project validation


package management - XR interaction toolkit 
install package by name - com.meta.xr.sdk.all
when the error pops up, say yes then withdraw 
fix things in validation, do android first
if error to install newer xr plug in version, go to package manager - open xrplug in = show versions - install the latest
go back to android and fix more problems 
go to openXR - make sure API layers, meta XR feature and foveation (blurry stuff around paripherals to mimic human sight), and oculus touch proximity are all checked
back to build settings, make sure the run device is the quest

thats it

close everthing and go to the meta tab at the top, building block, install camera rig and whatever else you need
